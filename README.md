# 🗄️ SQL: Database Design & Querying (MySQL)

SQL scripts showing how to build databases and query them in **MySQL**.

| File | Concepts |
|---|---|
| `Create_Alter_Drop_Table.sql` | Creating, changing and dropping tables |
| `SQL_Constraints.sql` | PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL and CHECK constraints |
| `ONE-TO-MANY Relationship.sql` | Relational design with linked `author` and `book` tables |
| `INNER_JOIN_Police.sql` | INNER JOIN between officers and police stations |
| `LEFT_RIGHT_JOIN.sql` | LEFT and RIGHT JOIN, including rows with no match |
| `Multiple_Rows_Subqueries.sql` | Subqueries that return multiple rows (IN) |
| `Group by.sql` | Aggregation with GROUP BY |
| `students_survey_mysql.sql` | Full database dump of a student survey dataset |

## How to run
Open a script in MySQL Workbench (MySQL 8.0+) and run it.
